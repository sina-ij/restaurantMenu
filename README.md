# منوی دیجیتال رستوران و کافه (QR Menu)

یک وب‌اپلیکیشن چندمستأجری (multi-tenant): هر رستوران/کافه یک حساب ادمین جدا
دارد و یک صفحه‌ی منوی عمومی با آدرس اختصاصی خودش که با اسکن QR باز می‌شود.

## پیش‌نیازها

- Node.js نسخه ۱۸ یا بالاتر
- PostgreSQL (می‌تونه لوکال باشه یا یک سرویس آنلاین رایگان مثل Neon یا Supabase)

## راه‌اندازی قدم‌به‌قدم

### ۱. نصب پکیج‌ها

```bash
npm install
```

### ۲. تنظیم دیتابیس

فایل `.env.example` رو کپی کن و اسمش رو بذار `.env`:

```bash
cp .env.example .env
```

داخل `.env` مقدار `DATABASE_URL` رو با اطلاعات دیتابیس پستگرس خودت جایگزین کن.
اگه پستگرس رو لوکال نصب نکردی، ساده‌ترین راه ساخت یک دیتابیس رایگان روی
[neon.tech](https://neon.tech) یا [supabase.com](https://supabase.com) هست —
بعد از ساخت پروژه، یک connection string بهت میدن که همون رو اینجا می‌ذاری.

مقدار `JWT_SECRET` رو هم با یک رشته‌ی تصادفی طولانی جایگزین کن (هر متن طولانی
و غیرقابل‌حدس کافیه).

### ۳. ساخت جدول‌های دیتابیس

```bash
npx prisma migrate dev --name init
```

این دستور جدول‌های `User`، `Restaurant`، `Category` و `MenuItem` رو
تو دیتابیست می‌سازه.

### ۴. اجرای پروژه

```bash
npm run dev
```

حالا می‌تونی به آدرس `http://localhost:3000` بری.

## استفاده

1. از صفحه‌ی اصلی روی «ساخت منوی رستوران من» بزن و یک حساب بساز.
2. وارد داشبورد ادمین می‌شی؛ اونجا دسته‌بندی (مثل «پیش‌غذا»، «نوشیدنی گرم»)
   و بعد آیتم‌های منو رو با نام، قیمت، توضیح و عکس اضافه کن.
3. دکمه‌ی «کپی لینک منو» آدرس عمومی منوت رو کپی می‌کنه — همون آدرسیه که
   باید تبدیل به QR کد بشه و روی میزهای رستوران بذاری.
4. برای ساخت QR کد از لینک، می‌تونی از هر سایت رایگان QR-code generator
   (مثل qr-code-generator.com) استفاده کنی، یا بعداً این قابلیت رو مستقیم
   به پنل اضافه کنیم.

## نکات مهم قبل از انتشار عمومی (Production)

- **آپلود عکس**: در حال حاضر عکس‌ها روی دیسک سرور ذخیره می‌شن
  (`public/uploads`). این روش برای توسعه خوبه، ولی روی پلتفرم‌های
  serverless مثل Vercel فایل‌سیستم موقتیه و عکس‌ها بعد از مدتی پاک می‌شن.
  برای production باید `app/api/upload/route.ts` رو طوری تغییر بدی که
  عکس‌ها رو در Cloudinary، AWS S3 یا مشابه اون آپلود کنه.
- **دامنه**: وقتی پروژه رو دیپلوی کردی (مثلاً روی Vercel)، لینک منو به شکل
  `yourdomain.com/menu/restaurant-slug` در میاد.
- **امنیت رمز عبور**: رمزهای عبور با bcrypt هش می‌شن؛ `JWT_SECRET` رو
  حتماً قبل از انتشار عوض کن و جایی عمومی نذار.

## ساختار پروژه

```
app/
  page.tsx                  ← صفحه‌ی اصلی/معرفی
  menu/[slug]/page.tsx       ← صفحه‌ی عمومی منو (چیزی که مشتری می‌بینه)
  admin/login, register      ← ورود و ثبت‌نام ادمین
  admin/dashboard            ← پنل مدیریت منو
  api/                       ← تمام API routeها (auth، categories، menu-items، upload)
components/
  DashboardClient.tsx        ← منطق تعاملی پنل ادمین
lib/
  prisma.ts                  ← اتصال به دیتابیس
  auth.ts                    ← هش رمز و JWT
  getCurrentRestaurant.ts    ← گرفتن رستوران کاربر لاگین‌شده
prisma/
  schema.prisma              ← مدل‌های دیتابیس
```

## قدم‌های بعدی پیشنهادی

- تولید خودکار QR کد داخل پنل ادمین (با یک پکیج مثل `qrcode`)
- امکان تغییر رنگ برند و لوگو از داخل پنل
- ترتیب‌دهی دستی دسته‌ها و آیتم‌ها با درگ‌اند‌دراپ
- صفحه‌ی «فراموشی رمز عبور»
- چندزبانه کردن منوی عمومی (فارسی/انگلیسی)
